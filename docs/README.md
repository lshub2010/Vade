# Vade Agent Runtime（Vade）文档包

> 一个「内核极薄、能力全靠模块」的 Agent 运行时。core 只做连接、路由、循环、密钥、审计；工具、记忆、模型、客户端全部是独立进程，主动接入。

全称 **Vade Agent Runtime**，中文「偕行」；简称 **Vade**，用于代码、包名、URI scheme 与协议版本。本文档集正文统一用简称。

## 四、怎么开工（三步）

1. 建仓库骨架与 `CODEOWNERS`（照 `agents/01-contracts.md` §五）。
2. 按 `agents/00-orchestration.md` 的 W0 派三个 spike（C0a/b/c），硬时限 3 天。
3. C0 出结论后进 W1（C1），此后严格按波次表推进；每批交付后新开上下文跑 R1/R2，C/M/F 批加 R3。

## 五、术语

| 词 | 含义 |
|---|---|
| core | 唯一可信进程：连接、路由、循环、密钥、审计、配置页 |
| 模块 | 独立进程，主动接入；可跨机器、可单独运行 |
| 上游 MCP | bridge 连的外部 MCP server。**不是模块**：不握手、不注册、不可路由 |
| skill | 跨模块的编排知识，本地 `SKILL.md`。**不含执行通道**，只能用已有工具 |
| manifest | 模块自描述的能力清单，注册时校验 |
| KAT | 已知答案测试，锁死协议行为 |
| 五道门 | 模块交付门禁：独立运行/测试/部署/失败/观测 |
| seq | core 分配的会话事件序号，多端同步与重放的唯一依据 |
| 三通道 | 状态编码必须颜色 + 线型双通道（防色弱与灰度截图失真） |
