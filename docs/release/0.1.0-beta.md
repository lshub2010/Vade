# Vade 0.1.0-beta

状态：**已发布（pre-release）**，tag `v0.1.0-beta`，28 个资产。**独立审查未完成**，发布说明已如实标注。

## 范围

Beta 把需求文档里绝大多数的运行时能力补齐，相对 `0.0.5-alpha` 的主要变化：

| 领域 | 内容 |
|---|---|
| 记忆 M4a | 两层记忆、去重、supersedes、评分淘汰、会话 TTL、重启稳定召回、`remember`/`recall`/`forget`、`memory/read_session` 与六个 `memory/admin_*` 私有 RPC |
| core 接线 | `MemoryPort` 适配器、引擎会话层注入、`/admin/api/memory*` 六路由替换 501、写审计/读不审计、无编辑端点 |
| 管理面 | `/memory` 页面：统计、筛选、分页、详情（supersedes 链）、晋升 / 归档（必填理由）/ 恢复；浏览器只读时不渲染写按钮 |
| 自进化 M4b | 五个触发器、提案只进 `skills/pending/`、`consolidate` 幂等、启动补跑、关闭时零动作；默认关闭 |
| MCP 桥 M5 | stdio / HTTP 上游、前缀与冲突、未知 risk=high、动态能力更新保留旧表、2 MB 上限、凭据脱敏、拆实例隔离 |
| 多模型 | 多个 model 模块可同时注册；priority 选默认、`llm.model_module` 可固定；`chat` 不再进入模型工具表 |
| SDK | `on_rpc` / `on_event` / `call_tool(context=)` / `current_call_context()`；未注册私有 RPC 返回 `NOT_FOUND` |

契约不变：rpc `1.8.0`（50 方法）、events `2.0.0`（34 事件）、34 错误码。新增的七个模块工具与六个管理路由都在既有契约内。

## 已知缺口

- **M4b 的 LLM 触发器没有生产端点**：规则层与 consolidate 可用，`turn_review` / `session_close` / `skill_evolve` 需要注入模型调用。
- **T3 仍非完整验收**：客户端真模块 e2e 在 CI 缺模块源码时 `Assume.assumeTrue` 跳过。
- **独立审查缺失**：按门禁，未取得独立签字的批次不合并、不发布。
- **iOS、生产签名、商店分发、集群化**：本版本不做。
- **真机验证**：IME、AGSL、Web 配对未在真实设备验证。
