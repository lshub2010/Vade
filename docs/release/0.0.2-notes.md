# Vade 0.0.2-alpha

Second alpha of Vade (偕行). This is a pre-release: protocol, data formats and UI may still change. Back up before upgrading.

## What's in this release

### Core

- Session attach bounds and snapshot clipping: long histories no longer fail with `PAYLOAD_TOO_LARGE`; snapshots are trimmed with explicit `truncated` / `omitted` markers and audit.
- Deeply nested approval arguments are preserved instead of being silently dropped.
- Configuration plane: dotted keys expand into nested JSON, hot vs restart-required is reported truthfully.
- Admin plane: refresh-token persistence, logout revocation, CSRF double-submit, single-instance lock.
- Transport: device auth mode, Origin/Sec-Fetch-Site checks, read-only sessions, per-session event routing.
- UI sessions: `sha256(token)` persisted to `data_dir/ui_sessions.json` (0600, atomic write); a core restart no longer invalidates paired devices.
- Admin UI: the release tree now mounts `admin-ui/dist`, so `/login` serves the SPA and `/assets` loads; setup/audit/settings pages remain limited.

### Client

- Android application id normalised to `io.github.lshub2010.vade`.
- Connection status badge in the top bar and a mid-chat notice: connecting / reconnecting (with backoff) / offline.
- Ask-user cards (text / single choice / multiple choice / confirm) with timeout, Esc and snapshot recovery.
- Pairing survives restart; startup probe only clears credentials on 401/403/handshake rejection.
- Switching back into a session reloads full history; multi-session events are routed by owner session id.
- Navigation fixes: new-session failure is visible, archived sessions are reconciled, back keeps selection.
- Web first pairing: `POST /ui/session` can return the session token in the body for same-origin/allowlisted pages, so wasm is no longer blocked by unreadable `Set-Cookie`.
- Chat fixes: edit uses the real message id, cancel settles the bubble, attach happens once.
- Effects/back-layer lifecycle fixes; dark-mode agent reply colour.
- Blur/glass rendering fixes for API 24–30 and the composer/top-bar bands.

## Known gaps

- Real-model tool-call end-to-end (T3) is deferred; the built-in/mock paths are covered.
- Upstream `/v1/models` auto-discovery is deferred to 0.0.3; model lists are declarative today.
- iOS, memory/M4b and mcp-bridge are not in this release.
- The APK is debug-signed; desktop artifacts are unsigned.
- Some device-specific behaviour (IME, AGSL refraction, real-network handover) is verified on desktop CI only.
