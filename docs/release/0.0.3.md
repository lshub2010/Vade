# 0.0.3 发布范围（已实现 core 端）

从 0.0.2 明确延期，避免混入 alpha 0.0.2 的发布范围。

## 模型接入体验

- [x] 上游 `/v1/models` 自动发现：管理员填 `base_url` + key 后可“拉取列表”，core 通过 provider 请求 `{base_url}/models`，把结果并入 `model/list`（带来源、上次刷新时间、失败原因）。
- [x] 客户端模型选择器支持“刷新列表”。
- [ ] 区分“声明式模型”和“上游发现模型”的来源标记（未交付，wire 上都是 `provider=builtin`）。
- [ ] 多模型模块并存：现在模型模块的判定工具固定为 `chat`，跨模块同名工具触发 `TOOL_CONFLICT`；需要单独 RFC（工具索引按 module_id 命名空间化，或模型模块专用通道）。
- [ ] 真模型端到端工具调用（T3）：真 core + 真 model 模块 + echo，模型自主调用四个工具、审批卡按序出现。
