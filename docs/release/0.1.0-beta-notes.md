# Vade 0.1.0-beta

**这是 Beta 预发布版。** 协议与数据格式在本版本冻结；界面行为仍可能调整。不要用它承载唯一副本。

校验和见本页 `SHA256SUMS` 资产。

## 本版重点

- **记忆（M4a）**：会话/全局两层、去重、supersedes、评分淘汰、7 天会话 TTL、重启稳定召回；`remember` / `recall` / `forget` 工具与 `memory/*` 私有 RPC。
- **记忆治理**：管理面 `/memory` 页面与六个 `/admin/api/memory*` 路由（列表、详情链、统计、晋升、归档、恢复）；写操作审计，浏览器会话只读。
- **自进化（M4b）**：`turn_end` / `turn_review` / `session_close` / `consolidate` / `skill_evolve` 五个触发器；提案只进 `skills/pending/`，默认关闭。
- **MCP 桥（M5）**：stdio/HTTP 上游、工具前缀、未知 risk=high、动态能力更新、2 MB 上限、凭据脱敏、拆实例隔离。
- **多模型模块并存**：按 `manifest.priority` 选默认，`llm.model_module` 可固定；模型通道 `chat` 不再进入模型工具表。
- **SDK**：`on_rpc` / `on_event` / `current_call_context()`。

## 已知缺口（发布说明必须保留）

- **未经独立审查**：本版本的各批次由实现方自查，独立审查因工具额度耗尽未完成。发布物按“可用但未经第三方复核”对待。
- **M4b 的 LLM 触发器没有生产端点**：规则层与 `consolidate` 可用；`turn_review` / `session_close` / `skill_evolve` 需要注入模型调用。
- **T3 非完整验收**：客户端真模块 e2e 在 CI 缺模块源码时跳过。
- **iOS、生产签名、自动更新、集群化**：未做。
- **真机未验**：IME、AGSL、Web 配对。

## 升级提示

- 0.0.5 没有记忆数据，本版直接新建 `memory.db`，无迁移步骤。
- 模块需先在内核停机时加入 `identity/whitelist.json`，并设置 `CORE_PUBLIC_KEY`；不支持模块配对码。
- 版本号：core `0.1.0-beta`，客户端 `vadeVersion=0.1.0-beta`、`versionCode=6`。
