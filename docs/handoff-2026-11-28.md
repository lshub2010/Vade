## 5. Windows 平台差异（跑测试前必读）

- **权限位断言**：`admin/test_passwords.py`、`admin/test_password_migration.py`、`test_skill/test_install.py` 里 `0600/0700` 的检查有 `os.name != "nt"` 守卫，Windows 上跳过；安全相关的收紧**只能在 Linux 验**。
- **`fcntl` advisory lock**：`admin/test_password_migration.py` 有一条 `skipif(os.name == "nt")`。
- **符号链接**：`test_skill/{test_proposal,test_loader,test_install}.py` 共 4 处 `os.symlink`，**没有 Windows 守卫**。Windows 需要开启「开发者模式」或以管理员身份运行，否则这 4 条会 `OSError: [WinError 1314]`。这不是代码 bug，但会显示为失败——先确认开发者模式再判断。
- **可执行位**：`test_skill/test_install.py` 里按 `st_mode & 0o111` 判断「安装文件不可执行」的循环在 Windows 上恒真（空校验），别把绿灯当通过。
- **路径形式**：bash 里用 `/d/...`，传给原生程序（git/cargo/python）用 `D:/...`；不要写反斜杠。
- **`python` 不是 venv**：始终显式用 `.venv/Scripts/python.exe`。
