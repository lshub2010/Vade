# Alpha 0.0.2 发布记录

状态：**已发布（2026-11-23）**
版本：`0.0.2-alpha`，所有仓库统一 tag `v0.0.2-alpha`。

- 统一 Release：<https://github.com/lshub2010/Vade/releases/tag/v0.0.2-alpha>
- 客户端 Release：<https://github.com/lshub2010/vade-client/releases/tag/v0.0.2-alpha>
- 模块 Release：`https://github.com/lshub2010/vade-module-{echo,fs,shell,web,model}/releases/tag/v0.0.2-alpha`

## 范围

- 客户端：debug 签名 APK、Windows MSI/免安装 zip、Web wasm zip。
- core：`vade-core-0.0.2-alpha-linux-{x86_64,aarch64}.tar.gz`（含 `libvade_protocol.so`、schema、SDK、admin-ui、安装脚本、校验和）。
- 模块：`vade-module-{echo,fs,shell,web,model}` 各出 `py3-none-any` wheel + sdist + 独立 manifest。
- 文档：中英双语 README（默认英文、互链）、生产部署教程、`deploy/` systemd/docker-compose/反代样例。
- APK 使用 debug 签名；应用 ID `io.github.lshub2010.vade`。

- 真模型端到端工具调用验收（T3）。
- iOS、memory/M4b、mcp-bridge、生产签名与更新通道。
