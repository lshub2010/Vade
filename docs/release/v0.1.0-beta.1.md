# Vade 0.1.0-beta.1

`v0.1.0-beta` 的补丁预发布，只含发布后独立复审发现的问题修复。

## 修复

- **时间筛选 400**：core 的 `from`/`to` 统一转为整数秒，模块也接受有限浮点时间戳；`inf`/`nan` 返回 400 而不是 500。
- **缺记忆模块返回 501**：`MemoryAdapter` 在无可用节点时返回 `UNSUPPORTED`，管理页不再把“未安装”显示成“条目已消失”；缺失条目仍是 404。
- **`chat` 通道越权（安全）**：声明 `chat` 的模块必须只有 `chat` 一个工具，registry 直接拒绝，catalog 与 provider 双重过滤。此前任意模块可凭 priority 成为 LLM provider。
- **私有 RPC 边界**：handler 异常报 `INTERNAL`（不再伪装 `NOT_FOUND`）；返回非对象报错，不再渲染成空页。
- **归档理由**：按 C-16 的 300 字符上限校验，超长返回 400，不再静默截断。
- **版本/发布**：`CORE_VERSION` 取自 `__version__`；CITATION 与模块索引更新；发布流水线支持 `v0.1.0-beta.*`，标题与发布说明按 tag 取。

## 验证

- `core/tests` 全量 **1615 passed**
- memory 模块 **173 passed**
- SDK `sdk/python/tests` **66 passed, 2 skipped**
- 契约 / 台账 / 文档门禁通过

## 已知缺口（不变）

- 本补丁的独立复审在修复完成后重跑；结论以复审报告为准。
- M4b 的 LLM 触发器仍无生产模型端点。
- T3 仍非完整验收；iOS、生产签名、真机 IME/AGSL/Web 配对未做。
