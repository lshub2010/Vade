查知识库之前先想清楚要回答哪个问题：一次 recall 换一个能用一句话回答的问题。

## When to Use

- 用户问「之前为什么这么定」「当时选了什么方案」。
- 用户要求把一条结论写进知识库（写之前必须先 recall 查重）。

## Procedure

1. 用 `recall` 查关键词，不要一次贴整段对话。
2. 命中后引用决策 id，不要复述全文。
3. 写入前先 recall 同主题，避免重复条目。
4. 写入后把新 id 回给用户。

## Pitfalls

- 不要把「我记得」当成「知识库里有」。
- 不要在没查重的情况下写入，重复条目比缺失更难清理。
- 不要引用不存在的决策 id。

## Verification

回答里至少有一个真实存在的决策 id，且 recall 能再次查到它。
