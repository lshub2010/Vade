# Alpha 口径与验收清单

> 本文档定义「第一个 alpha 版本」的含义。**在此之前，仓库里没有 alpha 的定义**——里程碑表只有 G1–G5，全部标「未达成」，且 `release/`、`tests/e2e/` 不存在、`deploy/` 只有 README。
>
> 状态：**草案**。口径需产品侧确认后转正。

## 一、为什么需要一个「小口径」alpha

G1–G5 是**发布级**目标（端到端 + SDK 冻结 / 审批审计闭环 / 三端聊天 / iOS 真机 / 抓包 0 泄漏）。按 G5 口径，alpha 必须等六个模块（fs/shell/web/memory/mcp-bridge/model）齐备、admin 前端完成、M4b 自进化完成——这是数周量级。

但在那之前有一个更高优先级的问题：**「架构到底对不对」还没被真实验证过**。当前客户端协议层 19/33 方法、UI 全部假数据；真模块只有一个 `echo`（4 个 trivial 工具，用途是证明管道）。在这种情况下继续堆模块，是在未验证的地基上加层。

所以先做**口径 A**：让整条链路真跑起来，用最小成本证伪架构错误。

## 二、三个口径

| 口径 | 含义 | 估时 | 何时选它 |
|---|---|---|---|
| **A 桌面 alpha** | 本机双击可用：真连接、真聊天、真流式、echo 模块可调、能打包分发 | 3–5 天 | **默认**。先验证架构 |
| **B 可交付 alpha** | A + `fs` 与 `model` 两个真模块 + APK 真机验证 + Web 可写安全评审 | 1.5–2.5 周 | 要给外部试用者 |
| **C G1–G5 全绿** | 六模块齐 + admin 闭环 + 抓包 0 泄漏 | 3–5 周 | 正式发布前 |

**估算不是承诺**。依据是 2026-11-13～14 的实测速度（服务端 378 → 1041 测试、客户端 21 → 154 测试、单棒 28–69 分钟、12 路并行）。若回执质量不达一半，估时要 +50%。

## 三、口径 A 的验收条件（逐条可验）

### A1 连接与凭证
- [ ] 客户端能在本机连上 core（`ui/attach` 成功，拿到 32-hex session id + 快照）
- [ ] 首次运行有配对流程（一次性配对码或等价机制），**不把 token 明文落日志**
- [ ] 断线后自动重连（指数退避，有上限），界面上有明确连接状态

### A2 真聊天
- [ ] 发送消息走 `ui/submit`，返回 `turn_id` 与 `queue_pos`
- [ ] 流式增量走 `turn.delta`，界面逐字上屏（不是等完成再整段替换）
- [ ] `turn.completed` 后消息落库，重启客户端仍可见（走 snapshot 恢复）
- [ ] 中断（`ui/interrupt`）后已生成文本仍可见（RFC-0013 的 partial 语义）
- [ ] 错误有可读提示（34 个错误码至少按四类呈现：可重试 / 需重连 / 需用户操作 / 致命）

### A3 模块可用
- [ ] `echo` 模块在线时，模型能调用它的四个工具，工具卡在会话内正确渲染
- [ ] 模块离线时给出明确提示（不是静默失败）
- [ ] 审批（`approval/decide`）以内联卡片出现在会话里，**不弹独立窗口**

### A4 会话管理
- [ ] 会话列表、新建、重命名、置顶、归档、删除可用
- [ ] 分组创建 / 改图标 / 改颜色 / 删除可用（删组不删会话）

### A5 可分发
- [ ] 桌面端有明确的分发产物（安装包或免安装目录 + 启动脚本）
- [ ] 版本号单一来源，界面「关于」页可见
- [ ] 干净机器上能启动（不依赖本机 `D:/Hermes/tools` 里的任何路径）

### A6 质量门
- [ ] 服务端全量测试全绿（当前基线 1041）、契约检查 OK、文档门禁 12/12
- [ ] 客户端全量测试全绿（当前基线 154）、三端编译通过
- [ ] `gitleaks` 与私钥 grep 0 命中
- [ ] 桌面真机截图 ≥3 张（亮/暗、会话/能力/活动）
- [ ] **Android 运行时验收**：在 API 37 模拟器（手势导航，验 edge-to-edge 安全区）与 API 30 真机（验 miuix-blur 降级不崩）上各装一次，启动无崩溃、底栏不被系统手势条压住，截图存档

## 五、波次计划（口径 A）

| 波 | 内容 | 预估 |
|---|---|---|
| W1 | 协议补齐 + 真数据层 + 元数据/输入/用量/子代理 UI + 暗色 + 工具修复 | 进行中（12 路并发） |
| W2 | 数据层接线到 UI（会话列表 / 聊天流 / 状态机）、模块页入口、搜索接真接口 | 4–6 棒，约 3–4 小时 |
| W3 | 打包与分发（桌面产物、版本号、关于页、启动脚本）、首次运行配对引导 | 4–6 棒，约 3–4 小时 |
| W4 | 端到端联调：本机 core + 桌面客户端真跑，逐个修阻塞项 | 2–3 轮，约 1 天 |

**W4 是唯一无法并行、也无法预估的一波**——它就是把假数据换成真数据之后暴露出来的所有问题。

## 六、不做（口径 A 明确排除）

- iOS（用户 2026-11-13 决定暂缓）
- 六个模块里除 `echo` 外的全部
- admin-ui 前端
- M4b 自进化
- 抓包 0 泄漏的正式验收（口径 C 才做）
