# Alpha 0.0.2 发布筹备

状态：进行中（2026-11-23）
版本：`0.0.2-alpha`，所有仓库统一 tag `v0.0.2-alpha`。

## 范围

- 客户端：debug 签名 APK、Windows MSI/免安装 zip、Web wasm zip。
- core：`vade-core-0.0.2-alpha-linux-{x86_64,aarch64}.tar.gz`（含 `libvade_protocol.so`、schema、SDK、安装脚本、校验和）。
- 模块：`vade-module-{echo,fs,shell,web,model}` 各出 `py3-none-any` wheel + manifest。
- 文档：中英双语 README（默认英文、互链）、生产部署教程、`deploy/` systemd/docker-compose/反代样例。
- 发布门禁：T2/T4/T6 e2e 证据；T1/T5 修复；T3 真模型 e2e 列为 known gap。
